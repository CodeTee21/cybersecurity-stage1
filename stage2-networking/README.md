# Stage 2: Networking Fundamentals

## Introduction
This project documents my understanding of basic networking concepts as part of my cybersecurity learning journey.

## 1. What Is a Network?
A network is a group of connected devices that communicate and share information.

## 2. LAN and WAN
- **LAN:** Connects devices within a small area, such as an office.
- **WAN:** Connects devices across large geographical areas.

## 3. IP Address
An IP address identifies a device on a network and helps data reach the correct destination.

## 4. MAC Address
A MAC address identifies a network interface on a local network.

## 5. Router
A router connects different networks and directs data between them.

## 6. Switch
A switch connects devices within the same local network.

## 7. DNS
DNS translates domain names, such as `google.com`, into IP addresses.

## 8. Ports
Ports help a computer direct network traffic to the correct service. HTTPS commonly uses port 443.

## 9. TCP and UDP
- **TCP:** Provides reliable data delivery.
- **UDP:** Prioritizes speed without the same delivery guarantees as TCP.

## 10. HTTP and HTTPS
HTTP is used to transfer web data. HTTPS protects data in transit using encryption.

## Conclusion
Learning these networking concepts has helped me understand how devices communicate and how networking knowledge supports cybersecurity.
