\# Computer Fundamentals and Basic Security



\## What is a Computer?



A computer is an electronic device that accepts data, processes it, stores it, and produces information.



\## Hardware



Hardware is the physical part of a computer that we can touch.



Examples:

\- CPU

\- RAM

\- Storage

\- Keyboard

\- Mouse



\## Software



Software is a set of programs or instructions that tell a computer what to do.



Examples:

\- Windows

\- Linux

\- Microsoft Word



\## CPU



The CPU is the part of the computer that processes instructions and performs calculations.



\## RAM



RAM is temporary memory that holds programs and data the computer is currently using.



\## Storage



Storage keeps files and data for a long time, even when the computer is turned off.



\## Operating System



An operating system is software that manages the computer and allows the user to interact with it.



Examples:

\- Windows

\- Linux

\- macOS

\- Android



\## Files and Folders



A file contains saved information, while a folder is used to organize files.



\## Processes



A process is a program that is currently running on a computer.



\## Permissions



Permissions control what a user or program is allowed to do with a file or system resource.



Examples:

\- Read

\- Write

\- Delete
